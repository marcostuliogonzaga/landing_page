Projeto Bikcraft
Este é um projeto simples de página HTML/CSS criado para fins de aprendizado, testes e para treinar o envio de projetos para o GitHub.

📄 Sobre
A página simula um site de uma empresa fictícia chamada Bikcraft, que vende bicicletas personalizadas.
O objetivo foi praticar:

Estruturação com HTML5

Estilização com CSS3

Layout responsivo simples

Uso de Flexbox e Grid

Organização de conteúdo em seções

Tecnologias utilizadas
HTML5

CSS3

 Status
 Finalizado (para fins de aprendizado)
